# Security

Please don't report security problems in public issues.

Use GitHub's [private vulnerability reporting](https://github.com/U-Cut/u-cut/security/advisories/new) instead. Include the steps to reproduce the problem and what an attacker could do with it.

U-Cut is a pre-release project maintained in spare time, so replies may take a few days.

Two kinds of report matter most here:

- Anything that sends a user's media or API key off their Mac without their consent.
- A template or registry entry that can run code or reach the network when it renders.
