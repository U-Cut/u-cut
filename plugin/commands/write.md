description: Write a reel's script and make it with U-Cut
argument-hint: What the reel is about, and any photos to use
---

Write and make a reel with the U-Cut tools about: $ARGUMENTS

1. If they named photos or a folder, call `read_media` to see the scenes.
2. Write the script yourself: 3 to 8 words a line, about 3 words a second, a hook first and a soft close, with `scene` set where a line is about one of their scenes. Show them the lines.
3. Call `write_reel` with your `lines`, their `paths` if any, and a vibe that fits. Use the voice from `catalog` unless they ask for another.
4. Give them the path to the MP4.
