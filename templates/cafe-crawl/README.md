# Café crawl

Each place in the order you went, with every stop numbered.

Two quick tastes open the reel. Whenever 30 minutes or more pass between photos, the next shot
starts a new stop, and each stop's first shot is tagged "Stop 1", "Stop 2" and so on, so the reel
reads as a route. A day with only one stop gets no tags. Photos without a capture time stay in.

Made by the U-Cut contributors. Apache-2.0.
